# Flutter Profile UI

A modern, responsive **Profile Page UI built with Flutter**, featuring smooth interactions, custom design tokens, and full **light/dark theme support using Material 3**.

---

## ✨ Features

* 🎨 Modern UI with **Light & Dark Mode support**
* 🧠 System-based theme switching (Material 3)
* 🧑 Profile avatar with online indicator
* 📊 Interactive stats cards (Projects, Followers, Experience)
* 🔘 Animated Follow/Unfollow button using `setState`
* 💬 Message action button UI
* 📄 Structured About Me section
* 🧾 Clean profile details layout
* 🎯 Custom design system with reusable components
* 📱 Fully responsive Flutter UI

---

## 🧠 Key Concepts Used

* StatefulWidget (`setState` for follow toggle)
* Theme switching (Light/Dark mode with `ThemeData`)
* Material 3 (`ColorScheme.fromSeed`)
* Layout building with:
  * `Stack`, `Positioned`, `Column`, `Row`
* Reusable widget helpers:
  * `_buildStatCard`, `_buildSection`, `_buildDetailRow`
* Smooth animations (`AnimatedContainer`)
* Adaptive UI design for light & dark themes

---

## 🎨 UI Design Highlights

* Clean modern profile layout
* Soft gradients and card-based UI
* Proper contrast for both themes
* Dark mode optimized for AMOLED-like experience
* Light mode optimized for readability
* Consistent spacing system and typography
